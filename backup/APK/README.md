# Respaldo de APK — Dota 2 Build Assistant

Este directorio conserva los APK binarios de versiones estables cuando exista un paquete Android generado.

## Regla de nombres
`Dota2-Build-Assistant-vX.YY-YYYY-MM-DD.apk`

Cada versión debe acompañarse de:
- versión visible de la aplicación;
- commit fuente de Git;
- fecha de generación;
- SHA-256;
- resultado de instalación/prueba;
- referencia a la publicación o archivo conservado.

Los archivos APK son históricos: no se reemplazan ni se sobrescriben.
